# BAARO — i18next

## Dépendances
```bash
npm install i18next react-i18next
```

Ou via `package.json` mis à jour (versions `i18next@^23`, `react-i18next@^15`).

## Fichiers
| Fichier | Rôle |
|---------|------|
| `i18n.js` | Init + RTL + localStorage |
| `locales/fr.json` `en.json` `ar.json` | Traductions |
| `src/main.jsx` | `import "../i18n.js"` en premier |
| `src/components/Navigation.jsx` | `useTranslation` → `nav.*` |
| `src/features/settings/index.tsx` | `save({ lang })` → `setAppLanguage` |

## Usage dans un composant
```jsx
import { useTranslation } from "react-i18next";

function MyComponent() {
  const { t, i18n } = useTranslation();
  return <button>{t("common.cancel")}</button>;
}
```

Clés imbriquées : `t("nav.feed")`, `t("shop.register_title")`, `t("auth.send_code")`.

## Changer la langue
```js
import { setAppLanguage } from "../i18n.js";
await setAppLanguage("ar"); // fr | en | ar
```

Réglages UI : choisir Français / English / العربية appelle déjà `setAppLanguage`.

## RTL
Arabe → `document.documentElement.dir = "rtl"` automatique.
